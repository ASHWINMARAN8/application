## 📲 Install & Run Alexa on Your Phone

Choose your preferred way to install:

### Option 1: Direct Android App (APK) — Recommended for Full Phone Control
1. **[📥 Download Alexa Android APK (v1.0.0)](https://github.com/ASHWINMARAN8/application/releases/download/v1.0.0/Alexa-Offline-AI-v1.0.0.apk)**
2. Tap the downloaded file to install on your Android device.
3. Grant permissions for Microphone, Calls, SMS, and Torch.
4. Enable **Accessibility Service** when prompted to allow hands-free voice automation.
5. Say **"Alexa"** anytime to control your phone 100% offline!

### Option 2: 1-Click Mobile Web App (PWA)
1. Open 👉 **[Alexa Live Web App](https://ashwinmaran8.github.io/application/)** on your phone's browser (Chrome or Safari).
2. Tap the **"INSTALL PHONE APP"** button or browser menu (⋮) -> **"Install App"** / **"Add to Home Screen"**.
3. Alexa installs directly to your home screen and operates 24/7 full-screen with offline caching!

## 🌟 Overview

**Alexa (Echo Edition)** is a personal voice AI assistant inspired by **Amazon Echo & Alexa**. It features the signature cyan/blue glowing light ring, authentic Alexa offline chimes, crystal-clear polite speech cadence, and touchless mobile voice automation in **Tanglish**, **தமிழ்**, and **English**.

### What makes it special:
- 🔵 **Iconic Amazon Echo Light Ring**: Authentic glowing and rotating cyan/deep blue gradient light ring that responds smoothly when listening, thinking, and speaking.
- 🔔 **100% Offline Audio Chimes**: Generates authentic Alexa wake and confirmation chimes locally using Web Audio API (zero external media downloads, zero latency).
- 🎙️ **Alexa Voice Engine**: Natural, polite, courteous speech output with high clarity and smooth pacing.
- 📴 **100% Offline & Private**: Zero data sent to the cloud, zero external API latency, 100% private edge processing on your device.
- 🗣️ **Trilingual Support**:
  - **Tanglish** (*"Sure! Torch on pannitten."*, *"Amma-kku ippo call panren."*, *"Battery 88% irukku!"*, *"Sound 80% kku kootitten."*)
  - **Pure Tamil (தமிழ்)** (*"டார்ச் ஆன் செய்யப்பட்டது."*, *"போன் திரை திறக்கப்பட்டது."*, *"அம்மாவுக்கு இப்போது கால் செய்கிறேன்."*)
  - **English** (*"Sure, turning on flashlight."*, *"Device unlocked touchlessly."*, *"Calling David now."*)
- 🔓 **Touchless Screen Control**: Unlock or lock phone displays using only your voice ("Alexa, phone ah unlock pannu") without touching the screen.
- 🎭 **Dual Alexa Personas**:
  - **Alexa Echo Core**: Signature Cyan & Deep Electric Blue light ring, friendly smart assistant tone.
  - **Alexa Echo Show**: Amber Gold smart display hub theme.
